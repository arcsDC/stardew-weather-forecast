# stardew-weather-forecast

A Stardew Valley SMAPI mod that displays the next three days' weather forecast in the top-right corner of the screen.

## Stack

Primary language: **C#**

## Project structure

- `Mod.cs` — Display upcoming weather forecast on the HUD
- `mod.json` — SMAPI mod manifest

## Usage

Review the source files and install any dependencies referenced by the project before running it.
